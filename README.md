## 🔧 Using SpaceChatDB Basics

Once you open SpaceChatDB, here is how to get started with your chat database.

### Creating a new chat database

1. Click "New Database" or "Create"
2. Enter a name for your chat database
3. Click "Save" to create it on your computer

### Adding chat messages

With a new database open, you can add chat messages manually:

- Click "Add Message"
- Type the message, sender name, and date/time
- Click "Save" to store the message

### Searching your chat data

Use the search bar at the top:

- Enter keywords or phrases you want to find
- Press Enter or click the search icon
- Results will show messages with your terms highlighted

### Organizing chats into categories

To keep chats neat:

- Click "Manage Categories"
- Add new category names, like "Family" or "Friends"
- Assign messages to categories to sort them for easy access
